Supported program commands

Upload a JSON program file.

Arithmetic and variables A–Z; assignment with → or ->; input such as ?"X="→A; Disp, quoted text, Lbl, Goto, If condition⇒Goto label, If … Then / Else / IfEnd, For … To … Step … / Next, While … LpWhile, While … WhileEnd, Do … LpWhile, Prog, Return, Stop, and Error "message" to stop with a custom error.

Graph commands: ViewWindow xMin, xMax, xScale, yMin, yMax, yScale, PlotOn X, Y, PlotOff X, Y, Line x1, y1, x2, y2, ClrGraph, and ClrText. Conditions support =, <, >, <=, >=, <>, And, Or, and Not. Functions include SIN, COS, TAN, SQRT, ABS, LOG, LN, EXP, INT, FRAC, and ROUND. Lines starting with ' are comments.

Example: ?"X="→A then A^2→B then Disp B. Program memory is approximated by UTF-8 source size, with a shared 24 KiB limit.

This is an independent educational simulator. It does not reproduce every fx-9700GE feature or guarantee identical results to original hardware.

Separate from the fx-180P simulator.
